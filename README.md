# CRC_project_UPSSC_reg.form_TUSHAR_016

## 📌 Project Overview
This is an **Online Examination Registration Form** created for **CRC PROJECT**. It is designed using **HTML5**, **CSS5** and **JS5** with a clean, modern, and responsive user interface.

The form allows users to enter their personal, educational, and examination details in an organized layout.

---

## 🚀 Features
- Responsive registration form design
- Clean and attractive user interface
- User-friendly input fields
- Dropdown selection options
- File upload for photo and signature
- Password field for account security
- Mobile-friendly layout

---

## 🛠️ Technologies Used
- HTML5
- CSS5
- JS5

---

## 📋 Form Fields Included
1. Full Name  
2. Father's Name  
3. Mother's Name  
4. Date of Birth  
5. Gender  
6. Email Address  
7. Mobile Number  
8. Aadhaar Number  
9. Category  
10. Qualification  
11. Exam Center  
12. Address  
13. Upload Photo  
14. Upload Signature  
15. Password
